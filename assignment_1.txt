Q1. Difference Between Frontend, Backend, and Full-Stack Development

Frontend: The visible part of a website that users interact with.
Example: Product display page on Amazon.
Technologies: HTML, CSS, JavaScript.

Backend: The behind-the-scenes part that manages data, logic, and communication with the server.
Example: User login system that verifies data in the database.
Technologies: Node.js, Python, Java, PHP.

Full-Stack: A developer skilled in both frontend and backend development.
Example: A developer building both the login page and the backend system that processes login details.

Q3. How a Browser Requests and Displays a Web Page

1. The browser sends a request to the web server.
2. The server processes the request and fetches the required data.
3. The server sends the response (HTML, CSS, JS files) back to the browser.
4. The browser renders the page and displays it to the user.

Q4. Tools Required for Web Development Setup

1. VS Code – Write and edit code (HTML, CSS, JS).
2. Web Browser (Chrome/Firefox) – Test and preview web pages.
3. Git & GitHub – Version control and project backup.
4. Node.js – Run JavaScript outside browsers and manage packages.
5. Command Prompt / Terminal – Execute commands, run servers, and install dependencies.

Q5. What is a Web Server?

A web server is software or hardware that stores, processes, and delivers web pages to clients (browsers) upon request.
When a user enters a URL, the web server sends the corresponding files to display the page.

Examples:
i) Apache HTTP Server
ii) Nginx
iii) Microsoft IIS
iv) LiteSpeed

Q6. Roles in a Web Development Project

Frontend Developer – Designs and builds the visual interface using HTML, CSS, and JavaScript.
Backend Developer – Develops server-side logic, APIs, and database connections.
Database Administrator (DBA) – Manages, secures, and optimizes the database; handles backups and performance.

Q7. Setting Up VS Code for Web Development

1. Download and install Visual Studio Code from [https://code.visualstudio.com](https://code.visualstudio.com)
2. Install useful extensions: Live Server, Prettier, HTML CSS Support, JavaScript Snippets.
3. Create project files: index.html, style.css, and script.js.
4. Right-click on index.html → select “Open with Live Server” to preview in a browser.

Q8. Static vs Dynamic Websites

Static Website – Displays fixed content for all users; no database or user interaction.
Example: Portfolio, Company Info Page

Dynamic Website – Content changes based on user data or input; connected to a database.
Example: Facebook, YouTube, Amazon

Q9. Web Browsers and Rendering Engines

Google Chrome – Blink – Fast and modern engine used widely.
Mozilla Firefox – Gecko – Open-source engine developed by Mozilla.
Safari – WebKit – Default browser engine for Apple devices.
Microsoft Edge – Blink – Chromium-based, similar to Chrome.
Opera – Blink – Uses Chromium engine with built-in tools.
