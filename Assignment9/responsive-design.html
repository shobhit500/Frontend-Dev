Responsive Design Principles

Fluid Layouts

Use percentage-based widths so elements scale with screen size.

.container {
    width: 90%;
}

Flexible Media

Images and videos scale automatically to fit the container.

img {
    max-width: 100%;
}

Breakpoints

Adjust layout using media queries at specific screen widths.

@media (max-width: 600px) {
    body { padding: 10px; }
}
